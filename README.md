Coffee Counter ☕

A simple, offline-first web app to track your daily coffee consumption (AMA Classic & Nescafé packets).

Features
- Count packets for AMA Classic and Nescafé
- Track estimated caffeine and daily cost
- 7-day chart and history
- Dark / Light theme
- Works completely offline (data saved in browser)

How to use
Just open `coffee-counter.html` in any browser.
